# Tool Usage Policy
Before executing any tool that modifies files (such as `write_to_file`, `replace_in_file`, or `apply_diff`), you **MUST** strictly follow this procedure:

1. **Explain the Plan**: briefly verbalize in a single sentence specifically what you are going to change and why.
2. **Show the Intent**: briefly describe in a single sentence the logic behind the change.

**DO NOT** execute the tool immediately without this explanation step.
Even if the user asks for a quick fix, you must state your action plan first.
